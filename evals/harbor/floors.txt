# Per-task reward floors for the scheduled Harbor run, one `<task> <floor>` per
# line. `gate.sh` enforces them; with no entries it enforces nothing and says so.
# Trials whose reward.json carries `agent_api_error: 1` (credit lapse, rate
# limit, auth failure — stamped by lib/assert.sh) are excluded from the mean and
# reported as skipped; a task with only such trials reads as no usable results
# and fails, so an unfunded run can never pass a floor by accident.
#
# A floor guessed before a week of scheduled runs either never fires or fires on
# every run, and both are worse than no floor. So there is one entry here, and
# it is not a guess about quality: "writes nothing when nobody can select" does
# not vary with the model. It either holds, or the plugin has regressed to
# reading transcripts unattended — the failure the manual-distill release exists
# to remove.

distill-unattended 1.0
